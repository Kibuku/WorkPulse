How WorkPulse understands your work

WorkPulse combines small signals. It does not record keystrokes or continuously take screenshots.
Active app and windowSamples the foreground window every five seconds and groups continuous activity into sessions.
Idle timeStops treating time as active after 60 seconds without keyboard or mouse input.
File changesNotices files created, changed, moved, or deleted in selected work folders. It records metadata, not every document's contents.
Browser and calendar contextReads supported active browser tabs when permission allows and uses an optional calendar feed to understand meetings.
Your personal layer stays yours.

Raw titles, URLs, file paths, personal activity, captures, and detailed history remain on this machine. Organization updates contain only the summary you preview and choose to copy or send.
